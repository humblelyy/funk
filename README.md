# FUNK — Video Editor Portfolio

React + TypeScript + Vite + Tailwind CSS + Framer Motion portfolio for Karan Gorai / FUNK.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import the project into Vercel. The project uses Vite and the included `vercel.json` points Vercel at the `dist` output.

## Included updates

- Single infinite logo marquee using transparent uploaded logos.
- Logo marquee is monochrome/white-blended and moves left-to-right.
- Projects use the `no-img.webp` placeholder instead of the previous flower/mountain artwork.
- Smooth section reveal animations.
- Animated hero title.
- App-style glass navigation.
- HUMBLE build credit and HUMBLE & FUNK copyright footer.
